# ASCII 도식 표준 (ASCII Diagram Standards)

## MANDATORY (필수): 기본 ASCII 문자만 사용

**CRITICAL (필수)**: 도식에는 항상 기본 ASCII 문자만 사용한다 (호환성 최대화).

### ✅ 허용: `+` `-` `|` `^` `v` `<` `>` 및 영문자 · 숫자 텍스트

### ❌ 금지: Unicode 상자 그리기 문자
- 금지: `┌` `─` `│` `└` `┐` `┘` `├` `┤` `┬` `┴` `┼` `▼` `▲` `►` `◄`
- 이유: 글꼴 · 플랫폼마다 표시가 일정하지 않음

## 표준 ASCII 도식 패턴

### CRITICAL (필수): 문자 폭 규칙
**상자 안의 모든 줄은 반드시 정확히 같은 문자 수 (공백 포함) 를 가져야 한다**

✅ 올바름 (모든 줄 = 67자):
```
+---------------------------------------------------------------+
|                      Component Name                           |
|  Description text here                                        |
+---------------------------------------------------------------+
```

❌ 잘못됨 (폭이 일정하지 않음):
```
+---------------------------------------------------------------+
|                      Component Name                           |
|  Description text here                                   |
+---------------------------------------------------------------+
```

### 상자 패턴
```
+-----------------------------------------------------+
|                                                     |
|              Calculator Application                 |
|                                                     |
|  Provides basic arithmetic operations for users     |
|  through a web-based interface                      |
|                                                     |
+-----------------------------------------------------+
```

+-------------------------------------------------------+

```

+----------+

+----------+
     |
     | HTTP POST
     v

|  Target  |
+----------+
```

```
+-------+     +-------+     +-------+
| Step1 | --> | Step2 | --> | Step3 |

```

## 검증

도식을 만들기 전에:
- [ ] 기본 ASCII 만 사용: `+` `-` `|` `^` `v` `<` `>`
- [ ] Unicode 상자 그리기 문자 없음
- [ ] 정렬에는 탭이 아닌 공백 사용
- [ ] 모서리는 `+` 사용
- [ ] **상자의 모든 줄이 같은 문자 폭** (공백 포함 문자 수 세기)
- [ ] 테스트: 고정폭 글꼴에서 모서리가 세로로 맞는지 확인

## 대안

복잡한 도식은 Mermaid 사용 (`content-validation.md` 참조)
