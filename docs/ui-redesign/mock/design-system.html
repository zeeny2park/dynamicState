2. 상태 어휘

판정과 검사가 쓰는 같은 네 가지 상태 + 진행 중. 단어·색·아이콘이 화면과 보고서에서 같다
상태검사 행배지판정뜻
FAIL✖이상 발견판정: CONFIRMED_FAULT검사가 찾던 이상을 발견함
INCONCLUSIVE?판단 불가판정: PROBABLE_FAULT실행했지만 답을 내지 못함. 정상이라는 근거가 아님
PASS✔통과판정: HEALTHY끝까지 실행했고 아무것도 발견하지 못함
SKIPPED–실행 안 함판정: INCONCLUSIVE실행하지 않음. 정상이라는 근거가 아님
RUNNING진단 중—지금 실행 중 (라이브 UI에만 있음)
